# 🎬 Cinema Booking System (Java Console Application)

A simple, interactive command-line application built in **Java** that simulates a movie theater ticket booking experience. Users can browse available movies, view theater seating layouts, reserve seats, and generate booking summaries directly from the terminal.

---

## 🚀 Features

* **Movie Listings:** View currently showing movies along with showtimes and ticket prices.
* **Interactive Seat Map:** Displays real-time seating availability (marking open vs. booked seats clearly).
* **Ticket Reservation:** Select specific seats and book single or multiple tickets in one session.
* **Booking Confirmation:** Automatically calculates total ticket cost and prints a booking receipt/summary.
* **Input Validation:** Prevents double-booking already reserved seats and handles invalid menu choices gracefully.

---

## 🛠️ Technologies Used

* **Language:** Java (JDK 8 or higher)
* **Interface:** Command-Line Interface (CLI) / Standard Console I/O (`Scanner`)
